# KVANT Launcher

Свободный лаунчер для Minecraft, созданный для тех, кто хочет играть без проблем.

## Возможности

- Запуск всех версий Minecraft (Release, Snapshot, Alpha, Beta)
- Forge / NeoForge / Fabric / OptiFine из коробки
- Авторизация: Microsoft Account, Ely.by, Офлайн
- Кастомные скины
- Авто-диагностика и исправление конфликтов модов
- Галерея скриншотов
- Виртуальная сеть для LAN-игры (в разработке)
- Тёмная тема

## Скачать

Скачайте последний релиз из [нашего сайта](https://kvant-net.vercel.app/ru/KVLauncher.html)).

## Требования

- Windows 10/11 (x64)
- .NET 8.0 Runtime (обычно уже установлен)
- Java 17+ для Minecraft 1.17+

## Сборка из исходников

```bash
git clone https://github.com/JohnAG/KVANTLauncher.git
cd KVANTLauncher
dotnet build
```
